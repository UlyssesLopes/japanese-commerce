# Descubra sua rotina: etiquetas propostas

Proposta para a Carol conferir antes de marcar no backoffice. Tudo saiu do **texto de indicação e do
modo de uso que vocês já escreveram** em cada produto, nada de fora. Etiqueta errada leva o produto
para a pessoa errada, então vale ler com o rótulo na mão.

Como o site usa isto: cada pergunta só mostra as opções que algum produto **à venda** tem. Produto
sem etiqueta ou sem passo não entra no questionário. Maquiagem fica de fora.

## Etiquetas

- **Cabelo:** ressecado/frizz · danificado · fino, sem volume · opaco, sem brilho
- **Tipo de pele:** seca · oleosa ou mista · sensível. Produto marcado com um tipo só aparece
  para quem tem esse tipo. Produto sem tipo aparece para qualquer tipo, se bater com o incômodo.
- **Incômodo da pele:** manchas/tom irregular · poros e cravos · opaca, sem viço · linhas finas

## Passos (ordem de uso)

Limpeza → Preparo (loção) → Tratamento → Hidratação → Finalização
